# Exam 2 — Electrostatics

This program focuses on notes **8.1–8.6 and 9.1**: electric force, electric field, electric potential, and Gauss' law. Both Evo and CE Python receive the same study cards and physics solvers.

## Install and open

From the complete download, send all **40 `.py` files** in `TI84_EVO/EXAM2/TRANSFER`. Restart calculator Python and run **APC → Exam 2 electrostatics**, or run **EXAM2** directly.

The smaller `Exam2_Evo.zip` uses `Exam2_Evo/TRANSFER`. It includes the updated screen spacing and E-Field Studio. For a fresh install, use TRANSFER; do not also send UPDATE. [Installation steps](INSTALL.md).

**CE Python:** send all 13 files in `TI84_PLUS_CE_PYTHON/TRANSFER` (or the identical `TOPICS/EXAM2/TRANSFER` folder). Run APC or EXAM2. Rod/ring calculations and derivations are included in separate FIELD_STUDIO and FIELD_GUIDES topic folders to fit CE memory. [CE instructions](CE_PYTHON.md).

## Find a topic

| Topic | Menu |
|---|---|
| Charge, induction, conductors, methods and formulas | Study / formulas / concepts |
| Spheres, cylinders, lines, sheets and nonuniform spherical charge | Gauss law / flux solvers |
| Closed-surface and flat-surface flux | Gauss law / flux solvers |
| Work, final speed, uniform-field voltage, charge assembly | Work / energy / charge |
| Zero-field location and identical-sphere charge sharing | Work / energy / charge |
| Point-source field, potential and test-charge force | Point charges E V and force |
| Rods, rings, arcs, limits, extrema and derivations | Rod / arc / ring studio |

Use the same arrow controls as [E-Field Studio](EFIELD.md). Follow the unit and angle prompts; expression trig functions use radians. At number prompts, `q` then ENTER cancels.

Show your own symmetry arguments, dq, integral bounds, Gaussian surface choice, signs and conservation steps on paper. The calculator evaluates the model you select. Capacitors, RC circuits, magnetism and induction are not part of this stated Exam 2 scope, even where reference menus include them.
