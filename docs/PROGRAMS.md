# Program directory

Only launch the entry points described below. Other files are imported helpers and must still be transferred with their release. Identical names can contain different code across snapshots.

## Launchers

| Program | Purpose |
|---|---|
| `EXAM2` | Exam 2 launcher (Evo) |
| `EFIELD` | E-Field Studio launcher |
| `APC` | Main toolkit launcher; behavior depends on installed release |
| `APCHECK` | Full-course / reference self-check launcher |
| `EFCHK` | E-field physics and UI self-check launcher |
| `EFKEY` | Hardware-key calibration and navigation test launcher |
