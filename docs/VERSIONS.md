# Saved versions and updates

For a fresh install, use the ready-to-transfer folders in **APC_Complete.zip**. Its `VERSION_ARCHIVE` folder contains the smaller saved editions and updates below.

| Download | Purpose / when to use it |
|---|---|
| `APC_CE_Python.zip` | Current CE Python library: Exam 2, Mechanics, E&M, multi-step tools, calculus, graphs, complete field guides and formulas in smaller topic installs. |
| `AP_Physics_C_Evo_Fixed.zip` | Recommended Full APC edition. Mechanics + E&M; plain program files; fixes the original startup and memory issues. |
| `Share_AP_Physics_C_EM.zip` | Saved E-Field Studio sharing edition. For CE Python, use the current APC_CE_Python download; the older 34-file CE folder exceeds the documented workspace budget. |
| `Exam2_Evo.zip` | Complete Evo Exam 2 install, including the current banner-spacing fix. |
| `AP_Physics_C_Evo.zip` | Original Full APC edition. Historical; use the corrected edition for normal installation. |
| `APC_v3_Patch.zip` | Two-file compatibility update for an older corrected Full APC install. Already included in the current corrected edition. |
| `EField_Studio_Evo.zip` | Saved Evo E-Field Studio edition. The sharing pack is the simpler fresh installation. |
| `EField_Studio_v2_Patch.zip` | Navigation/readability update for an older compatible Evo field-studio install; eight files. |
| `EField_Navigation_Fix.zip` | Alternate saved copy of the same navigation update. |
| `EField_Studio_v3_Keyboard_Patch.zip` | Two-file keyboard/calibration update for an older Evo field-studio install. |
| `EField_Plain_UI_Update.zip` | One-file EFGUI update removing colored bars and correcting selection alignment. |
| `EField_Final_Formulas_Update.zip` | Three-file final-formula browser update for an older field studio. |
| `Exam2_Banner_Fix.zip` | One-file EFGUI update for an older Exam 2 install. Already included in the current Exam 2 download. |
| `APC_All_Versions.zip` | All saved calculator-program snapshots, including the Mechanics recovery files. For browsing older editions and recovery; choose one complete installation rather than mixing these folders. |

For an existing compatible Evo field studio, Exam 2's UPDATE folder has eight files. Send them together and restart Python. Do not send both UPDATE and TRANSFER.

Do not apply older field-studio or APC interface patches over Exam 2, or Evo interface files over CE Python. They can replace the newer menus or model-specific controls. Back up your own edits before replacement.
