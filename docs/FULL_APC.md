# Full APC — Mechanics + E&M

Use APC for the whole Physics C course on Evo or Plus CE Python.

## Install

From the complete download, send all **26 `.py` files** in `TI84_EVO/FULL_APC/TRANSFER`. This includes the multi-step Mechanics, E&M and lab tools. Restart calculator Python, then run **APC**. See [installation](INSTALL.md) for the transfer steps.

The smaller `AP_Physics_C_Evo_Fixed.zip` retains its older folder layout: send all 22 files in `TRANSFER_FIRST` plus the four files in `OPTIONAL_TOOLS` for the same complete toolkit.

**CE Python:** the same equation and tool library is split into smaller installs. Use `TOPICS/MECHANICS/TRANSFER` for Units 1–7, `TOPICS/EM_REFERENCE/TRANSFER` for Units 8–13, and `TOPICS/MATH_TOOLS/TRANSFER` for the multi-step, calculus and graph tools. Install one topic at a time and run APC. [CE installation and switching](CE_PYTHON.md).

## What it does

| Area | Tools |
|---|---|
| Mechanics | Kinematics, forces, energy, momentum, rotation, oscillations |
| E&M | Charges and fields, potential, capacitors, circuits, magnetism, induction |
| Multi-step problems | Projectiles, collisions, pulleys, rolling, SHM, charge superposition, circuit networks |
| Math and graphs | Numerical derivatives, integrals, roots, linear systems, ODEs, plots and regression |

Select a topic and equation, then choose the unknown. Read the variable units and assumptions before entering values. Equation graphs sweep a selected variable.

## Controls and inputs

The Evo full-course menus use **1–5**, then ENTER; **0** goes back and **8/9** changes pages. CE menus use arrows and ENTER, with CLEAR/0 to return. At number prompts, `q` then ENTER cancels. ENTER reuses a displayed value, and `ans` uses the previous result.

Use SI units and radians. Expressions such as `2e-9`, `pi/4` and `sqrt(2)` work. Include `*` between factors. Some unknowns need a continuous sign-changing numerical bracket.

If memory runs short, restart Python and launch APC directly. You can keep the 22-file core alone and omit the optional multi-step group files, using the smaller download's folder layout. See [troubleshooting](TROUBLESHOOTING.md).
