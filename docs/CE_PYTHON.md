# APC on the TI-84 Plus CE Python

The CE download includes the same Physics C content as the Evo collection: Exam 2, all 13 equation units, multi-step solvers, calculus, graphs, field derivations, and final formulas.

**The difference is installation.** TI limits the CE Python workspace to 50 KB, so the library is divided into smaller topic folders. Install **one topic at a time**. The complete feature library is in the download; it cannot all stay active together on a CE.

## Start with Exam 2

Send all **13 `.py` files** from `TI84_PLUS_CE_PYTHON/TRANSFER` using TI Connect CE. Choose **RAM**, keep names unchanged, quit/reopen calculator Python, then run **APC**. This is the same install as `TOPICS/EXAM2/TRANSFER`.

Open **Exam 2 electrostatics** for the same study cards, Gauss/flux solvers, work/energy, charge sharing, and point-source calculations. The rod/ring studio is in a separate topic below.

## Choose another topic

Each folder is under `TI84_PLUS_CE_PYTHON/TOPICS`. Send every `.py` file in its `TRANSFER` folder together, then run **APC**.

| Folder | What you get | Files |
|---|---|---:|
| `EXAM2` | Exam 2 concepts, Gauss/flux, work/energy, charge and point sources | 13 |
| `MECHANICS` | All seven Mechanics equation units; solve unknowns and graph equations | 18 |
| `EM_REFERENCE` | All six E&M equation units; solve unknowns and graph equations | 17 |
| `MATH_TOOLS` | All 15 multi-step tools, calculus, roots, linear systems, ODEs, regression and preset/custom graphs | 14 |
| `FIELD_STUDIO` | All five field models: calculations, extrema, inverse solvers, sketches, plots and final field formulas | 19 |
| `FIELD_GUIDES` | The complete five-model derivations and limits, including finite rod and ring proofs | 14 |
| `FINAL_FORMULAS` | Final field formulas, superposition formulas and every E&M reference equation | 14 |

For **Quiz 8.4**, use FIELD_GUIDES to study the proofs, FIELD_STUDIO for numerical work and plots, and FINAL_FORMULAS to browse answers. All of these are included.

## Switch topics without filling memory

1. **Quit the calculator's Python app.** Back up any APC files you edited.
2. In TI Connect CE's Calculator Explorer, **archive or remove the previous APC topic's files**. Its TRANSFER folder lists exactly which names belong to it. Leave unrelated personal programs alone.
3. Send the new topic's complete TRANSFER folder to **RAM**, replacing matching names. Do not send the default folder and another topic together.
4. Reopen Python and run APC. Keeping old topic files active can exceed the CE limit even when the new folder is small.

If other Python programs already fill the workspace, back them up and archive the ones you do not need. If memory is still tight, restart Python and use only the selected APC topic. Archived Python programs do not run until moved back to RAM.

Some menus link to content in another topic. They show a topic-change instruction instead of failing when that content is not installed. Switching requires Calculator Explorer; APC cannot move itself between RAM and Archive.

## Controls

The menus retain the same white background, light selection highlight, wrapped formulas and arrow controls. **↑/↓** selects, **ENTER** opens, **←/→** changes pages, and **CLEAR/0** returns. The CE edition uses its own keyboard codes and text positioning. Run **EFKEY** if navigation needs calibration; the learned keys last for that Python session.

The physics formulas and study text are shared with the Evo editions. Physical CE memory, navigation and rendering still need verification on the recipient's calculator. This package requires the **Python edition**; it cannot add Python to an ordinary CE.
