# APC — start here

## TI-84 Evo: Full APC

Open TI84_EVO/FULL_APC/TRANSFER and send all 26 .py files together with
TI Connect Evo: https://connectevo.ti.com/
Restart calculator Python and run APC. This includes Mechanics, E&M and
the multi-step tool groups.

## TI-84 Plus CE Python: APC E&M

Open TI84_PLUS_CE_PYTHON/TRANSFER and send all 34 .py files together with
TI Connect CE using Calculator Explorer. Choose RAM and keep filenames.
https://education.ti.com/en/products/computer-software/ti-connect-ce-sw
Restart calculator Python and run APC or EFIELD.
This is the E&M edition; the full Mechanics edition currently targets Evo.

## Other programs already included

TI84_EVO/EXAM2/TRANSFER — 40 files. Open APC or EXAM2.
TI84_EVO/EFIELD/TRANSFER — 34 files. Open APC or EFIELD.

Choose ONE installation at a time: their filenames overlap. Back up edited
copies before replacement. Send .py files, not ZIPs or guides. Your computer
does not need Python or coding tools. Restart calculator Python after updates.

Evo-T and CE-T Python use the corresponding family route. Other TI-84 models
without Python cannot run these files. See GUIDES/INSTALL.md for model details.

GUIDES contains individual program instructions and troubleshooting.
VERSION_ARCHIVE contains older editions and updates for recovery or separate use.
For normal installation, use the ready-to-transfer model folders above.
